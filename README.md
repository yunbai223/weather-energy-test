# 天气能量测试 · 部署上线指南（Gitee Pages）

本测试是**纯静态网页**（HTML + CSS + JS），无需服务器、无需数据库，
部署后即可通过链接分享给他人做题。当前版本**不含真实支付功能**，
结果页可免费查看；如需「付费解锁详细结果」，见文末「接入真实支付」说明。

---

## 一、发布到 Gitee 仓库（3 分钟）

### 1. 注册 / 登录 Gitee
打开 https://gitee.com 注册并登录。

### 2. 新建仓库
1. 点击右上角 **「+」→「新建仓库」**
2. 仓库名称：`weather-energy-test`（英文小写，会出现在网址里）
3. 是否开源：选「私有」或「公开」均可（私有更安全，链接同样可分享）
4. 其他保持默认，点击「创建」

### 3. 上传文件
方式一：网页直接上传（推荐，最简单）
1. 进入仓库首页 → 点击 **「文件」→「上传文件」**
2. 把 `weather-energy-test` 文件夹里的**全部内容**拖入：
   - `index.html`
   - `css/` 文件夹
   - `js/` 文件夹
3. 填写提交说明，点击「提交」

方式二：Git 命令行（适合后续更新）
```bash
cd C:\Users\24373\Desktop\weather-energy-test
git init
git add .
git commit -m "天气能量测试 v1.0"
git remote add origin https://gitee.com/你的用户名/weather-energy-test.git
git push -u origin master
```

## 二、开启 Gitee Pages 服务（2 分钟）

1. 进入仓库 → 点击顶部 **「服务」→「Gitee Pages」**
2. 部署分支：选择 `master`（或 main）
3. 部署目录：留空（保持默认根目录）
4. 点击「启动」
5. 等待约 30 秒~1 分钟，页面会显示部署地址：
   `https://你的用户名.gitee.io/weather-energy-test`

> ⚠️ Gitee Pages 需要**实名认证**后才能开启。
> 实名认证：个人中心 → 账号设置 → 实名认证（需绑定手机号 + 身份证，约 5 分钟）。

所有内容都在 `js/` 文件夹里，改完重新上传对应文件即可：

## 五、接入真实支付（进阶，需二次开发）

当前版本结果页免费展示全部内容。若要实现
「做完题 → 付费 → 才显示详细结果」，有两种方案：

### 方案 A：微信支付「Native 扫码」（推荐，个人可用）
1. 注册微信商户平台 https://pay.weixin.qq.com （需营业执照，费率 0.6%）
2. 需要一个**后端接口**（Node.js / Python / PHP 均可，可部署到
   腾讯云函数 / 阿里云函数计算 / Vercel 等）
3. 流程：
   - 用户答完题 → 前端把答案 POST 到后端
   - 后端生成「订单号 + 支付二维码」返回给前端展示
   - 用户扫码支付 → 微信回调后端 → 后端将「详细结果」返回给前端展示
4. 前端需新增一个「付费弹窗页」，隐藏结果页的详细区块，
   支付成功后再渲染。

### 方案 B：虚拟支付平台（无需写后端，适合小白）
使用 **面包多 / 爱发电 / 知识星球** 等平台：
1. 把详细结果做成「数字商品」上架，设置价格（如 ¥9.9）
2. 测试链接引导用户「做完题 → 跳转商品页购买 → 凭订单截图找你要完整报告」
3. 缺点：流程需要人工介入，不适合全自动体验

### 方案 C：邀请码 / 兑换码（零支付，先试运营）
1. 结果页默认显示**摘要版**
2. 你通过微信私下收款后，发给对方一个 6 位兑换码
3. 用户输入兑换码 → 解锁完整报告（前端校验，适合小规模验证需求）
